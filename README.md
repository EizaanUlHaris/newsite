# FARHIEN — Clothing Brand Website

A minimal, editorial clothing brand landing page built with Next.js and ready for GitHub + Vercel.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Deploy to Vercel

1. Push this folder to a GitHub repository.
2. Import the repository into Vercel.
3. Vercel will detect Next.js automatically.
4. Deploy — no environment variables are required.

## Customize

- Replace `public/logo.png` with your final logo file if needed.
- Product names, prices and images are in `app/page.js`.
- All styling is in `app/globals.css`.
- The current product/editorial photography uses Unsplash image URLs as temporary visual placeholders. Replace those URLs with your own campaign/product photography before launch.
